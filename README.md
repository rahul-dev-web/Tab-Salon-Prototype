# Tab Salon Prototype

Modern salon appointment-booking prototype for client demonstration.

## Demo flows

- Customer landing page
- Services and transparent pricing
- Appointment booking without customer account
- Date and available time selection
- Booked slot example
- Customer details and booking confirmation
- Demo admin dashboard
- Appointment queue
- Walk-in / chair status
- Manual slot blocking concept
- Conflict-awareness for walk-ins affecting upcoming appointments

## Run locally

This prototype is intentionally dependency-free.

Open `index.html` directly in a browser, or serve the folder with any static server.

## Production direction

For the proposed small salon project:

- Frontend: React/Next.js or equivalent
- Backend: Node/Next API
- Database: PostgreSQL/Supabase
- Admin authentication
- Customer: no account required; name + mobile at booking
- Confirmation: WhatsApp/SMS can be integrated separately
- Hosting: Vercel + Render/Supabase as appropriate

This repository is a UI/UX prototype, not the production booking backend.
